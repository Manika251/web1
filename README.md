# Portofolio El Putra Sarira

Website portofolio satu halaman. Dibuat dengan HTML, Tailwind CSS (CDN), CSS biasa, dan JavaScript.

## Struktur folder

```
portofolio-el-putra-sarira/
├── index.html            # kerangka halaman + kelas Tailwind
├── css/
│   └── style.css         # CSS tambahan di luar Tailwind
├── js/
│   └── script.js         # efek: nama menebal, cahaya kursor, animasi scroll
└── images/
    └── el-putra-sarira.jpg   # foto di hero
```

## Cara mencoba di komputer

Klik dua kali `index.html`. Perlu internet, karena Tailwind dan font diambil dari CDN.

## Cara online di GitHub Pages

1. Buat repo baru di GitHub (public).
2. Upload isi folder ini (jaga struktur foldernya: `css`, `js`, `images`, dan `index.html`).
3. Buka Settings > Pages, pilih "Deploy from a branch", branch `main`, folder `/ (root)`, lalu Save.
4. Tunggu 1-2 menit, buka `https://USERNAME.github.io/NAMA-REPO/`.
